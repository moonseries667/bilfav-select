# 外部 AI 分类表生成 Prompt

将以下 Prompt 与导出的 `video-dataset.json` 一起提供给外部 AI。保存返回的 JSON 数组为文件，再通过分类列表上方的文件导入控件载入。只有解析成功时才会一次性替换当前分类列表；失败时现有编辑内容保持不变。

```text
请根据我附上的 Bilibili 收藏视频数据，设计一份便于查找的个人分类表。

任务要求：
1. 分析所有可用视频的标题、简介、完整 tags、分区、UP 主和时长；unavailable=true 的记录跳过。若你无法完整读取附件，请说明缺失范围，不要假装分析过全部数据。
2. 依据附件内容生成最多 12 个普通类别，数量可以少于上限。类别应覆盖主要内容，合并相近类别，避免按单个角色、UP 主、作品名或零散主题建立大量收藏夹。
3. 每类 description 必须写清收录范围、明确排除范围，以及与相邻类别冲突时如何判断。依据是视频主要内容和类别定义，不是仅提及的主题。
4. 类别边界应相互兼容且可执行。若内容证据不足、定义之间存在无法消除的歧义，或视频不符合任何类别，由程序归入“不确定”。
5. 不生成“不确定”“其他”“未分类”等兜底类别；程序会自动保留“不确定”。不要逐条输出视频分类。
6. 只生成分类表，不要生成子类、树形结构或多标签。

输出格式：只返回严格 JSON 数组，不要 Markdown 代码围栏、前言或解释。每项只能包含两个字符串字段 name 和 description。名称简短、唯一，说明完整、可直接作为分类规则。

格式示例：
[
  {"name":"类别名称","description":"收录范围；排除范围；与相邻类别冲突时的判断规则。"}
]
```
